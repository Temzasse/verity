# Require external evidence for factual verdicts

Verity's initial article analysis can currently assign a misinformation category from model inference without retrieving evidence. We decided that factual verdicts require relevant external evidence; the initial analysis may identify claims worth checking but cannot establish falsity on model inference alone. This gives up an immediate factual judgment in favor of one readers can inspect against supporting material.

Use **Check the facts** in place of the initial **Misinformation / False claim** wording, preserving the other categories and techniques. **Unsourced claim** remains an observation about missing attribution, rather than a conclusion that the claim is false.

Use Google's Fact Check Tools claim search to retrieve published reviews as contributing evidence, rather than only related reading. A review may inform Verity's verdict only when it addresses the same claim and relevant circumstances. Show the publisher, review date, original rating, and link; distinguish the publisher's rating from Verity's assessment. Use applicable reviews alongside web research, retaining the existing web-checking route when no matching review is found. A loosely related review or an empty search result cannot establish a verdict.
